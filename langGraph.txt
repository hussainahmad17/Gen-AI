Agentic AI using LangGraph

LangGraph is used to build stateful (nodes/data) LLM workflows.
In LangGraph, we can define the control flow of the agents.

------------------------------------ Core Concepts ------------------------------------------------

1. Prompt Chaining:
A series of steps where the output from one LLM becomes the input for another.

2. Parallelism:
A situation where multiple LLM workflows can be executed simultaneously.

3. Routing:
A situation where a main LLM (the orchestrator) decides which LLM or flow the process should follow.

4. Graphs, Nodes, and Edges:
The complete workflow is represented as a Graph in LangGraph. Nodes are Python functions performing specific tasks, and edges determine the flow of execution (e.g., sequential, linear, or parallel).

------------------------------ Advanced Concepts --------------------------------------------------

Checkpoints and MemorySaver:
These are used to restore the agent's state, allowing agents to remember past conversations.
We define a `thread_id` to let the agent identify specific chat conversations, such as which conversation belongs to which user.

Persistence:
Persistence refers to the ability to save and restore the state of a workflow over time.
This can be implemented using the `InMemorySaver` class by passing the checkpointer object during the `compile()` stage.

Fault Tolerance:
If the workflow crashes, it can resume exactly from the point where it failed.
We can resume our workflow from the last known state by using the same `thread_id` and passing `None` as the input state, which will then be populated from the last state stored in memory. This provides fault tolerance, allowing us to recover from failures or interruptions.

Human-in-the-loop:
A situation where the workflow is interrupted and waits for human input before proceeding.

Time Travel:
The ability to go back to an earlier saved state of your agent and continue from there.
We can return to an earlier state by passing the specific `checkpoint_id`.
